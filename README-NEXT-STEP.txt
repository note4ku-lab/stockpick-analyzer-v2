STOCKPICK ANALYZER - STEP 1

Perubahan pada versi ini:
- Data historis Zapi dinaikkan dari 120 menjadi 250 candle.
- File lain tidak diubah.

Tujuan:
- Menyiapkan data yang cukup untuk indikator MA50, MA100, dan MA200 pada langkah berikutnya.

Cara penggunaan:
1. Extract ZIP ini.
2. Upload/replace isi project ke repository GitHub sesuai struktur project.
3. Pastikan ZAPI_API_KEY tetap tersimpan sebagai Environment Variable di Vercel.
4. Commit ke branch main.
5. Tunggu deployment Vercel sampai Ready.

Jangan hapus ZAPI_API_KEY dan jangan memasukkan API key ke dalam source code.
