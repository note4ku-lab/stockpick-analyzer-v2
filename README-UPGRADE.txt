STOCKPICK ANALYZER - INDICATOR DASHBOARD UPGRADE

Versi ini menambahkan:
- Data Zapi: 250 candle terakhir.
- MA5, MA20, MA50, MA100.
- RSI 14.
- MACD, Signal, Histogram.
- Volume dan Volume MA20.
- Ringkasan trend, momentum, dan volume.
- Tampilan kartu indikator dengan warna berbeda agar lebih nyaman dibaca.
- Kesimpulan analisa otomatis dalam Bahasa Indonesia.
- AUTO / SCALPING / DAY TRADE / SWING / LONG SWING tetap dipertahankan.
- Top Picks tetap menggunakan /api/analyze.

PENTING:
1. Jangan memasukkan ZAPI_API_KEY ke source code.
2. ZAPI_API_KEY tetap di Vercel Environment Variables untuk Production.
3. Upload/replace file sesuai struktur folder proyek.
4. Commit ke branch main.
5. Tunggu Vercel sampai status Ready.
6. Tes BBRI, BMRI, ANTM, dan INCO.

Catatan:
ZIP ini adalah paket proyek lengkap untuk menggantikan file proyek yang sesuai. Jika repository Anda memiliki file tambahan yang tidak ada di ZIP, jangan menghapus file tambahan tersebut secara manual; cukup replace file dengan nama/path yang sama.
